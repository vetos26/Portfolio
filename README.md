# NEURAL.DEV — портфолио AI-инженера

Адаптивное русскоязычное портфолио на HTML5, Bootstrap 5 и JavaScript. Тексты и изображения кейсов демонстрационные: они описывают концепты, а не запущенные продукты.

## Запуск

Требуется Node.js 20.19+ или 22.12+.

```sh
npm ci
npm run dev
```

Для сборки используйте `npm run build`. Готовый сайт находится в `dist/`; его можно разместить на любом статическом хостинге. Чтобы проверить сборку локально, запустите `npm run preview`.

## Как обновить портфолио

- `index.html` — название, тексты разделов и контактная ссылка. Замените ссылку GitHub на нужный канал связи.
- `src/main.js` — данные проектов, категории и описания для карточек.
- `src/style.css` — тема, размеры и адаптация под экраны.
- `assets/` — изображения (WebP) и favicon.

Форма брифа сохраняет текст в файл на устройстве посетителя. Сервер, отправка писем и сбор данных не используются.
